# Part 1: DEF-01 — Reichert Op. 5 Schott Score Engine Injection

### 1.1 Root Cause Analysis

In `FluteModes/FluteModes/Resources/score_template.html` and `FluteModesAndroid/app/src/main/assets/score_template.html`, lines 921–941 contain the dispatch hooks for Reichert:
```javascript
function renderScore(abcString) {
  const r1Match = abcString && abcString.match(/%\s*R1_SCHOTT_ART:(\d+):SEC:(\d+)/);
  if (r1Match) {
    renderR1Schott(parseInt(r1Match[1], 10) || 0, parseInt(r1Match[2], 10) || 0);
    return;
  }
  const r2Match = abcString && abcString.match(/%\s*R2_SCHOTT_ART:(\d+):SEC:(\d+)/);
  if (r2Match) {
    renderR2Schott(parseInt(r2Match[1], 10) || 0, parseInt(r2Match[2], 10) || 0);
    return;
  }
  const r4Match = abcString && abcString.match(/%\s*R4_SCHOTT_ART:(\d+):SEC:(\d+)/);
  if (r4Match) {
    renderR4Schott(parseInt(r4Match[1], 10) || 0, parseInt(r4Match[2], 10) || 0);
    return;
  }
  const r5Match = abcString && abcString.match(/%\s*R5_SCHOTT_ART:(\d+):SEC:(\d+)/);
  if (r5Match) {
    renderR5Schott(parseInt(r5Match[1], 10) || 0, parseInt(r5Match[2], 10) || 0);
    return;
  }
```

However, neither the data arrays (`R1_SECTIONS_DATA`, `R2_SECTIONS_DATA`, `R4_SECTIONS_DATA`, `R5_SECTIONS_DATA`, `REICHERT_ARTS_8`, `REICHERT_ARTS_12`) nor the functions (`renderR1Schott`, `renderR2Schott`, `renderR4Schott`, `renderR5Schott`, `buildR1SecAbc`, `buildR2SecAbc`, `buildR4SecAbc`, `buildR5SecAbc`, `formatReichert8`, `formatReichert4`, `formatReichert12Triplets`) are present in `score_template.html`.

In `build_reichert_outputs.py` lines 1687–1715, the injection logic failed because:
```python
target_hook = "    function renderScore(abcString) {"
```
specifies 4 leading spaces, whereas in `score_template.html` line 921, `function renderScore(abcString) {` has 0 leading spaces. As a result, `content.replace(target_hook, ...)` silently failed to match, and `score_template.html` was written back unmodified.

### 1.2 Exact Injection Specification

The Reichert block must be placed immediately preceding line 921 (`function renderScore(abcString) {`) enclosed in:
```javascript
// === BEGIN REICHERT OP5 SCHOTT ===
...
// === END REICHERT OP5 SCHOTT ===
```

#### Fix in `build_reichert_outputs.py`
In `build_reichert_outputs.py`:
1. Change line 1687 to:
   ```python
   target_hook = "function renderScore(abcString) {"
   ```
2. In lines 1469, 1471, 1536, 1538, 1605, 1607, 1679, 1681 of `build_reichert_outputs.py`, ensure all `ABCJS.renderAbc` calls include `add_classes: true`.
